# Font

Questo primo abbozzo usa Google Fonts via CDN (Anton + Barlow), caricati
nell'<head> di index.html. Se preferisci self-hostare i font (consigliato
per performance/offline), scarica i file .woff2 e mettili in questa
cartella, poi aggiungi le regole @font-face in css/scss/_base.scss al posto
del link a Google Fonts.
